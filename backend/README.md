# FreshGuard AI Backend

This is the FastAPI backend for FreshGuard AI.

- The backend will eventually receive sensor data from NodeMCU.
- The backend will eventually communicate with the ML prediction system.
- The backend will eventually store data in a database.
- The backend will eventually provide data to the React frontend.
- The current task only creates the backend skeleton.
- ML, database, IoT, and frontend integration are not implemented yet.
